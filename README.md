# Banquetería Paolicias

Aplicación de gestión de reservas para el servicio de Banquetería Paolicias. Esta aplicación permite la administración de usuarios, gestión de reservas y un panel de control para el administrador.

## 🚀 Características
- **Gestión de Usuarios**: Registro y login de usuarios.
- **Sistema de Reservas**: Interfaz intuitiva para solicitar servicios de banquetería.
- **Panel de Administración**: Control total sobre las reservas y usuarios del sistema.
- **Persistencia de Datos**: Implementación de base de datos local para almacenamiento eficiente.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje**: Kotlin
- **Framework**: Jetpack Compose
- **Base de Datos**: Room Database
- **Arquitectura**: MVVM (Model-View-ViewModel)
